# compare

## Usage
/compare <股票A> <股票B> [股票C] ...
例如：/compare 2330 2454 或 /compare AES-KY 6830 1590

## Instructions

當使用者觸發此 skill 時，請依序執行以下步驟：

### Step 1：解析輸入
- 識別使用者輸入的所有股票代號或名稱
- 確認每檔股票的代號與名稱對應

### Step 2：逐一搜尋各股資訊（盡量平行處理）

對每檔股票，同時執行：

**券商報告搜尋：**
- 使用券商報告工具搜尋每檔股票的相關報告
- 提取最新評等與目標價

**網路搜尋：**
- 使用 WebSearch 搜尋每檔股票的近期財務數據
- 關鍵搜尋項目：月營收、營收年增率、近期 EPS、本益比、股價
